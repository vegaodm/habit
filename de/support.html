Erste Schritte

Ihre erste Gewohnheit anlegen

  • Tippen Sie oben rechts auf der Startseite auf +.
  • Geben Sie einen Namen für die Gewohnheit ein, wählen Sie ein Symbol und eine Farbe und legen Sie einen Zeitplan fest (täglich, N-Mal pro Woche, bestimmte Wochentage, alle N Tage oder bestimmte Tage des Monats).
  • Aktivieren Sie nach Wunsch eine Erinnerungszeit.
  • Tippen Sie auf Speichern.

Check-in vornehmen

  • Tippen Sie auf das quadratische Kontrollkästchen rechts neben einer Gewohnheitszeile, um die heutige Aktivität sofort zu protokollieren.
  • Wenn Sie nach dem Abschluss erneut darauf tippen, können Sie den heutigen Eintrag wieder zurücknehmen.
  • Öffnen Sie eine Gewohnheit, um einen manuellen Eintrag mit Datum, Uhrzeit, optionaler Dauer und Notizen hinzuzufügen.
  • Tippen Sie in den Letzten Einträgen einer Gewohnheit auf einen beliebigen Eintrag, um seine Notiz hinzuzufügen oder zu bearbeiten. Notizen werden genau so angezeigt, wie sie eingegeben wurden; eine rein aus Ziffern bestehende Notiz wird unverändert dargestellt und nicht addiert.

FAQ

Wie sichere ich meine Daten?

Öffnen Sie das Menü oben links und wählen Sie Daten exportieren. Ihre Datenbank wird als Datei mit dem Namen habitlog-yyyy-MM-dd.sqlite gespeichert. Bewahren Sie diese an einem sicheren Ort auf (iCloud Drive, Computer usw.).

Wie stelle ich aus einem Backup wieder her?

Öffnen Sie das Menü und wählen Sie Daten importieren, und wählen Sie anschließend Ihr .sqlite-Backup aus. Eine Bestätigung weist Sie darauf hin, dass der Import alle vorhandenen Daten überschreibt. Nach der Bestätigung werden die Erinnerungen automatisch neu geplant.

Meine Erinnerung ist nicht ausgelöst worden.
  • Stellen Sie sicher, dass Mitteilungen aktiviert sind: iOS-Einstellungen > HabitsLog > Mitteilungen.
  • Prüfen Sie, ob die Erinnerung in der Gewohnheit aktiviert ist (Alarm-Symbol wird in der Liste angezeigt).
  • Erinnerungen werden nur für aktive (nicht archivierte, nicht gelöschte) Gewohnheiten ausgelöst.
Wie hoch ist das Limit für kostenlose Gewohnheiten?

Der kostenlose Plan unterstützt bis zu 8 aktive Gewohnheiten. Ein Upgrade auf HabitsLog Member schaltet unbegrenzt viele aktive Gewohnheiten, die App in weiteren Sprachen (Spanisch, Japanisch, Vereinfachtes Chinesisch, Koreanisch, Deutsch und Französisch) sowie den Import von Backups mit mehr als 8 aktiven Gewohnheiten frei. Erinnerungen, Statistiken, Anheften, Archivieren und Export sind in beiden Plänen verfügbar.

Wie kündige oder verwalte ich mein Abonnement?

Öffnen Sie iOS-Einstellungen > Dein Name > Abonnements (oder öffnen Sie den Member-Bildschirm und tippen Sie auf Abonnement verwalten). Das Abonnement verlängert sich automatisch, bis Sie es spätestens 24 Stunden vor Ende des laufenden Zeitraums kündigen.

Ich habe gekündigt, sehe aber weiterhin den Membership-Bildschirm.

Versuchen Sie auf dem Membership-Bildschirm Käufe wiederherstellen. Falls das Problem weiterhin besteht, stellen Sie sicher, dass Sie mit demselben Apple ID angemeldet sind, das für den Kauf verwendet wurde, und kontaktieren Sie uns dann.

Wie verschiebe ich eine Gewohnheit ins Archiv?

Wischen Sie über eine Gewohnheitszeile nach rechts, um sie zu archivieren (sie wird in den Archivbereich unten auf der Startseite verschoben). Wischen Sie im Archiv nach rechts, um sie wiederherzustellen, oder nach links, um sie zu löschen.

Was ist der Bereich "Gelöscht"?

Wenn Sie eine Gewohnheit löschen, wird sie nicht sofort entfernt. Sie wird in den Bereich Gelöscht unterhalb des Archivs verschoben und dort vorübergehend aufbewahrt, damit Sie sich noch umentscheiden können. Wischen Sie über eine gelöschte Gewohnheit nach rechts, um sie wiederherzustellen, oder nach links und bestätigen Sie, um sie endgültig zu entfernen. Eine auf diese Weise endgültige Löschung kann nicht rückgängig gemacht werden.

Wie ändere ich die App-Sprache?

Öffnen Sie den Bildschirm HabitsLog Member und scrollen Sie zum Bereich Sprache. Die Auswahl einer Sprache aktualisiert die gesamte App und plant Ihre Erinnerungen automatisch neu. Weitere Sprachen werden mit einer Mitgliedschaft freigeschaltet; kostenlose Nutzer können die App in Englisch verwenden.

Wie hefte ich eine Gewohnheit nach oben an?

Wischen Sie über eine Gewohnheitszeile nach rechts und tippen Sie auf Anheften, oder ziehen Sie eine Zeile auf die Ablegefläche Angeheftet, die angezeigt wird, solange noch nichts angeheftet ist. Angeheftete Gewohnheiten bleiben oben in genau der von Ihnen gewählten Reihenfolge. Für die Anzahl angehefteter Gewohnheiten gibt es keine Begrenzung.

Wie ordne ich meine Gewohnheiten neu?

Das Neuanordnen gilt für den Bereich Angeheftet: Drücken Sie längere Zeit auf eine angeheftete Zeile, um den Neuanordnungsmodus zu aktivieren, ziehen Sie den systemeigenen Griff an die gewünschte Position und tippen Sie dann auf Fertig. Gewohnheiten ohne Anheftung befinden sich im Bereich Vorschläge, der automatisch nach der nächsten Erinnerungszeit jeder Gewohnheit sortiert wird (nächste zuerst) und nicht manuell verschoben werden kann.

Synchronisiert HabitsLog zwischen Geräten?

Nein. HabitsLog ist vollständig offline und hat keine Konten. Um Daten auf ein anderes Gerät zu übertragen, verwenden Sie Daten exportieren, übertragen Sie die .sqlite-Datei und führen Sie auf dem anderen Gerät Daten importieren aus.

Sind meine Daten sicher?

Ja. Alle Daten liegen ausschließlich auf Ihrem Gerät in einer lokalen Datenbank. Die App erhebt keine personenbezogenen Daten und sendet nichts an einen Server. Details finden Sie in der Datenschutzerklärung.
